# 形象の画像

ここに PNG を置くと、アプリの仮の形象と自動で差し替わる（コードの変更は不要）。

- ファイル名：`lv{レベル}_{状態}.png`（例：`lv1_happy.png`）
- レベル：1〜6（覚えた単語 0 / 50 / 150 / 300 / 600 / 1000 語）
- 状態：`normal`（ふつう）、`happy`（正解）、`sad`（不正解）、`sleep`（今日の復習なし）
- そのレベルの画像がないときは、下のレベルの画像を使う。全部ないときは仮のドット絵。
- ドット絵は 32×32 か 48×48 がおすすめ（拡大しても `image-rendering: pixelated` でくっきり表示）。
